# Anomah Chat

**Version:** `1.0.16`  
**Owner & Publisher:** Mahi Muhtasim  
**Availability:** Web & Mobile  

---

## Overview

**Anomah Chat** is a private, proprietary real-time communication platform designed for fast, reliable everyday messaging and calling across desktop and mobile devices.

---

## Core Capabilities

- **Direct & Group Messaging:** Instant one-to-one conversations and managed group chats with replies, message reactions, editing, and read indicators.
- **Voice & Photo Sharing:** Seamless sharing of voice notes and images within conversations.
- **Audio & Video Calling:** Real-time one-to-one voice and video calls with live controls.
- **Quick Connect:** Connect effortlessly with contacts using personal invite links and QR codes.
- **Personalization:** Instant switching between **English** and **বাংলা**, along with selectable visual themes.
